Dynamic Syntax (DS) is an action-based, word-by-word incremental, semantic grammar formalism. To learn more, please check ["The Dynamics of Language", Cann et al. (2005)](http://www.lel.ed.ac.uk/~ronnie/cann-et-al-dec12.pdf).

Here you can find the implementation of a DS semantic parser (DyLan) in Java.
